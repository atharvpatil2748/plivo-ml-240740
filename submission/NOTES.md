# NOTES

The final model is a 4-layer GPT with `n_embd=192`, 4 attention heads, block size 128, and a byte-level tokenizer (vocab 256), totalling 1,902,720 parameters — 95.1% of the 2M cap. Increasing `n_embd` from 160 to 192 was the sole winning change: it scales all projection matrices simultaneously, giving the model significantly more representational bandwidth at every layer. The baseline was capacity-constrained, not regularization-constrained: only 67% of the parameter budget was used, so the model was underfitting. AdamW (Exp01) failed because weight decay is a regularizer and makes underfitting worse. The warmup + cosine schedule (Exp02) failed because cosine decay wastes effective steps in a very short 2,000-step run. Weight tying (Exp03) failed because it reduces capacity when more budget is available. The key engineering insight is to diagnose the active constraint first — here it was always model size, not training dynamics. Ablating one variable at a time confirmed this cleanly: only the capacity change improved BPB. The final BPB of 2.3472 represents a 1.04% reduction over the 2.3718 baseline using a single architectural parameter change.
