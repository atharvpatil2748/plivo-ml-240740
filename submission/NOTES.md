# NOTES

The final submission model is a 4-layer Modern Transformer combining RMSNorm, Rotary Position Embeddings (RoPE), SwiGLU gated activations, weight tying, and a Byte-Level BPE tokenizer (vocab 512). The parameter count is 1,869,504, utilizing 93.5% of the 2,000,000 parameter cap. Subword tokenization via Byte-Level BPE was the single largest breakthrough: it compresses raw multi-byte UTF-8 sequences (particularly Devanagari/Hindi bytes) into single subword tokens, effectively extending the context window without expanding sequence length. Rotary Position Embeddings (RoPE) eliminate learned absolute position embedding parameters completely while improving relative position modeling across attention heads. SwiGLU gated activations provide higher representational expressivity per parameter compared to standard GELU MLPs. Weight tying links the token embedding table to the output projection head, freeing up parameter capacity to expand layer dimensions (n_embd=192, n_head=6, hidden_dim=512). Optimizer and scheduler experiments (AdamW, cosine warmup) both failed because the 2,000-step training regime requires maximum step sizes throughout rather than decay. The combined modern architecture and BPE tokenizer dropped Dev Bits Per Byte (BPB) from 2.3718 to 2.0074, representing a 15.4% performance improvement over the baseline. The evaluation contract is strictly preserved with 100% byte-fallback lossless roundtrip verification.
